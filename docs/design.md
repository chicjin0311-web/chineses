# 혜진의 중국어 교실 디자인

## 방향
중국어 수업 자료를 한눈에 찾아 여는 폴더형 작업 공간. 첫 화면은 학습 자료, 수업 도구, 프로젝트, 나의 학습 노트 네 폴더를 중심으로 구성한다.

- 바탕 #FFFFFF, 표면 #FFFFFF, 글자·핵심 버튼 #202124, 보조 글자 #62646B, 경계선 #E1E2E5. 흰 바탕에 검정·중립 회색을 사용한다.
- 검정은 글자, 아이콘, 핵심 버튼과 선택된 메뉴에 쓴다. 화면의 넓은 영역과 폴더는 밝게 유지한다.
- 폴더의 탭, 가는 윤곽선, 작은 그림자로 폴더끼리 구분한다. 불필요한 큰 일러스트와 장식은 첫 화면에서 뺀다.
- 자료실, 수업 도구, 노트, 모바일 메뉴와 입력 컨트롤까지 같은 밝은 색상 체계를 적용한다.
- 한국어: Pretendard. 중국어: Noto Serif SC와 시스템 명조. 큰 중국어 낱말만 세리프를 사용한다.
- 왼쪽 고정 내비게이션, 네 개의 같은 크기 폴더, 간결한 자료 목록. 모바일에서는 두 열의 폴더와 하단 내비게이션.
- 홈과 프로젝트 목록은 `FolderCard`를 공유한다. 폴더 이름과 실제 자료 개수, 짧은 설명을 같은 순서로 배치한다.
- 약한 입체감만 유지하고 찾기 쉬운 정보 배치를 우선한다. 장식용 수치와 가짜 학생 활동은 넣지 않는다.
- 모든 페이지와 버튼은 키보드로 사용할 수 있고 reduced-motion을 존중한다.
