# 혜진의 중국어 교실 디자인

## 방향
중국어를 매일 조금씩 꺼내 쓰는 책상. 사무용 통계 대시보드보다 학습 재료와 도구가 주인공이다. 원고지, 병음, 단어 카드의 실제 기능이 시각적 정체성이 된다.

- 바탕 #F4F3EF, 표면 #FAF9F6, 글자 #283C34, 초록 #426854, 버터 #E8CF86, 살구 #E6B49D.
- 한국어: Pretendard. 중국어: Noto Serif SC와 시스템 명조. 큰 중국어 낱말만 세리프를 사용한다.
- 왼쪽 고정 내비게이션, 넓은 작업 영역, 비대칭 단어 카드와 안내 카드. 모바일에서는 하단 내비게이션.
- 뉴모피즘은 버튼과 컨트롤, 스큐어모피즘은 학습 카드와 프로젝트 폴더에 한정한다. 본문 대비를 유지한다.
- 시선의 중심은 첫 인사 你好 카드. 장식용 수치, 가짜 학생 활동, 자동 회전 효과를 넣지 않는다.
- 모든 페이지와 버튼은 키보드로 사용할 수 있고 reduced-motion을 존중한다.
